## Figures and manuscript

From a checkout with the manifest's local evidence paths present:

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MPLBACKEND=Agg \
  python scripts/build_revision_figures.py \
  --manifest docs/paper/revision_manifest_round2.json \
  --output-dir results/round2_rebuild_new \
  --install-dir docs/paper/generated
python scripts/build_submission_package.py \
  --layout one-column --output-dir results/round2_submission_new --install-pdf
python scripts/build_submission_package.py \
  --layout two-column --output-dir results/round2_submission_two_new --install-pdf
```

The PRAB one-column draft is the default; the alternate build installs only
`paper_twocolumn.pdf`. Both share `paper.tex` (see [PRAB formats](prab_submission.md)).

Use new output directories. The figure builder verifies the hash of every
consumed artifact. The submission builder rejects LaTeX errors, undefined
references/citations, BibTeX warnings and overfull boxes. Figures are written
without volatile PDF creation/modification dates. The raw simulation results
are ignored by git and must be supplied separately.

## Frozen attachment

From committed source, create a new bundle and verify it:

```bash
python scripts/build_evidence_bundle.py \
  --manifest docs/paper/revision_manifest_round2.json \
  --builder revision --verify \
  --output-dir results/journal_campaign_03/round2_evidence_bundle
```

The packager rejects dirty source because `git archive` uses the committed
snapshot. It copies all selected artifacts, scientific inputs and exact BTS
configuration byte-for-byte, writes the source archive and environment record,
and rebuilds in a temporary directory using the archived source and copied
evidence. Verification fails if the regenerated macros differ. The final
`SHA256SUMS` includes the verification summary before the tarball is written.
The [D13 completion record](../exec-plans/completed/156_round2_evidence_verification.md) records the actual bundle location, archive hash and verification outcome.

The bundle's `REBUILD.md` is the referee entry point. It explains installation,
hash verification and regeneration without the author's ignored result folders.
The local tarball is prepared for attachment; no DOI, external upload or public
artifact hosting is implied. A git push publishes the committed code and paper,
not this ignored attachment.

## Numerical studies and provenance

The selected BTS summary's adjacent `config.json` is included with its exact
recorded hash. The final beam and error budget, chamber configuration, ten
corrected lattices, per-seed correction records, chamber summaries, window scan,
independent trajectory audit, raw joint ensembles, checkpoint input specifications
and tuning results are included in the manifest. The stricter correction attempt
is retained as supporting evidence for the selected-scenario limitation.

Numerical reruns use the drivers and command lines described in
[corrected rings](round2_corrected_ring.md), [chamber](round2_chamber.md),
[final robustness](round2_robustness.md), [validation](round2_validation.md),
[transparency](round2_transparency.md) and [pulse](pulse_and_timing.md).
They require fresh result directories and much more computation than the frozen
figure rebuild. Checkpoint resume intentionally rejects changed inputs, source
or scientific settings; a new checkout path is not silently treated as the same
simulation job. Protected source notebooks, field spreadsheets and lattice data
are never regenerated by the publication rebuild.

```bash
sha256sum results/journal_campaign_03/round2_evidence_bundle.tar.gz
mkdir -p check && tar -xzf results/journal_campaign_03/round2_evidence_bundle.tar.gz -C check
(cd check/round2_evidence_bundle && sha256sum -c --quiet SHA256SUMS)
```

Outcomes:
- **Archive.** The hash matches the D13 record.
- **Inventory.** All 213 entries verify.
- **Isolated rebuild.** Running the archived source on the bundled evidence alone produces `journal_macros.tex`
  byte-identical to the archived manuscript macros, and to the macros installed in `docs/paper/generated` at
  commit `cdc71bf`.
- **Manifest.** Independently, all 205 artifacts of `revision_manifest_round2.json` are present in this checkout and
  match their recorded hashes.
