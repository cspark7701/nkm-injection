# Round-5 shared BTS model audit (G1)

The [final audit record](round5_companion_audit_final.json), generated by `scripts/audit_round5_models.py`, checks the nominal strengths, element sequence and bend geometry against the saved NKM jobs. All nine strengths are identical to the BTS article's matched reference. Both use the inherited entrance/exit optics and neither modeled line has a vertical corrector. Future correction hardware remains unspecified.

The stochastic models are not identical. NKM draws one common 0.05% relative dipole-field error for all BTS bending elements; the BTS article draws independent 0.05% errors by bend. Quadrupole gradient, independent offsets and roll have the same declared rms levels, but the random streams/populations differ. The NKM line uses ideal horizontal translation and finite-particle exit centroids; the BTS study uses fitted dipole trims and analytic centroids, with different aperture treatment and shot terms. The audit also records each model's numerical integration settings. No setting or scientific input is changed to force agreement.

The NKM values of about 0.90 mm / 77 microradians are population standard deviations across the 50 seed-42 ablation realizations. The underlying means are nonzero; the final record separately gives mean, population standard deviation and root mean square for each plane coordinate. The BTS values of about 1.07 mm / 0.096 mrad are root-mean-square values from its 200-machine, three-shot zero-jitter reference. These values must retain their own populations and definitions; the difference cannot be attributed solely to finite sampling from the present audit.

With the design emittance and entrance dispersion included, the nominal horizontal rms sizes are computed from the full covariance. The assumed 0.5 mm / 0.2 mrad booster jitter is 1.319 / 2.206 of those rms sizes, consistent with the companion's approximate 1.3 / 2.2. Both are stress/sensitivity assumptions, not measured KLS stability specifications.

The [round-5 protocol](round5_protocol.json) freezes the adopted point, core source/input identities, five paired jitter scales and statistical definitions before new tracking. It retains the production steering and all historical campaigns; the new scan evaluates ideal two-plane steering only. Existing zero/full endpoints will be reused only after source/configuration and pairing checks.

The original [declaration-time audit](round5_companion_audit.json) is retained unchanged because its digest is part of the frozen tracking protocol. The final precision audit corrects its approximate rms labels; it changes no model or tracking input.
